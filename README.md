# Formwork Designs

Company website for Formwork Designs, featuring drafting, formwork design, and project support services for the Australian construction industry.

## Development

Requires Node.js 22 or later.

```bash
npm install
npm run dev
```

## Verification

```bash
npm test
npm run lint
```

## Deployment

Pushes to `main` are automatically built and deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.
